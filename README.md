# 💣 지뢰찾기

## 게임 소개

기본 10×10 보드에 숨겨진 지뢰 10개를 찾아내는 클래식 지뢰찾기 게임입니다. 초급·중급·상급 난이도와 사용자 지정 보드 크기 및 지뢰 수를 선택할 수 있습니다. 주변 칸의 지뢰 수를 단서로 안전한 칸을 모두 열어 승리하세요.

## 어떻게 만들었나요

화면은 HTML, 스타일은 CSS, 게임 규칙과 동작은 바닐라 JavaScript로 각각 분리했습니다. 첫 클릭 후 지뢰를 배치해 시작 칸을 안전하게 보장합니다.

## freeform 버전과 비교했을 때

상단에서 기본·초급·중급·상급 난이도를 선택하거나 사용자 지정 행·열·지뢰 수를 적용할 수 있습니다. 사용자 지정은 5~30행, 5~30열, 지뢰 1개부터 칸 수보다 1개 적은 수까지 지원합니다. 글로벌 리더보드 및 서버 기록 저장, 양쪽 클릭 동시 입력(Chording)은 제공하지 않습니다.

## 실행 방법

`index.html`을 브라우저에서 열면 실행됩니다. 별도 설치나 빌드 과정은 필요하지 않습니다.

## 커스터마이징한 부분

첫 클릭 안전 배치, 빈 칸 자동 확장, 남은 지뢰 수와 000~999초 타이머, 승리·패배 상태 표시 및 재시작을 구현했습니다. 회색 입체 프레임, 빨간 LED 카운터, 눌림 효과가 있는 칸으로 고전 지뢰찾기 인터페이스를 재현했습니다.
