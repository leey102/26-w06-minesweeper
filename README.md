# 💣 지뢰찾기

## 게임 소개

10×10 보드에 숨겨진 지뢰 10개를 찾아내는 클래식 지뢰찾기 게임입니다. 주변 칸의 지뢰 수를 단서로 안전한 칸을 모두 열어 승리하세요.

## 어떻게 만들었나요

화면은 HTML, 스타일은 CSS, 게임 규칙과 동작은 바닐라 JavaScript로 각각 분리했습니다. 첫 클릭 후 지뢰를 배치해 시작 칸을 안전하게 보장합니다.

## freeform 버전과 비교했을 때

이 PRD 버전은 10×10 격자와 상단 중앙 상태 아이콘 재시작 버튼을 사용하며, PRD의 제외 범위에 따라 양쪽 클릭 동시 입력(Chording)은 제공하지 않습니다.

## 실행 방법

`index.html`을 브라우저에서 열면 실행됩니다. 별도 설치나 빌드 과정은 필요하지 않습니다.

## 커스터마이징한 부분

첫 클릭 안전 배치, 빈 칸 자동 확장, 남은 지뢰 수와 000~999초 타이머, 승리·패배 상태 표시 및 재시작을 구현했습니다. 난이도 선택, 사용자 지정 보드, 글로벌 리더보드 및 서버 기록 저장은 이번 범위에서 제외했습니다.
