# 💣 지뢰찾기

9×9 보드에서 지뢰 10개를 피해 안전한 칸을 모두 여는 지뢰찾기 게임입니다.

## 게임 소개

- 좌클릭으로 칸을 열고, 우클릭으로 깃발을 표시하거나 회수합니다.
- 열린 숫자 칸에서 좌·우 버튼을 함께 누르면, 주변 깃발 수가 숫자와 일치할 때 나머지 칸을 엽니다.
- 첫 번째로 여는 칸에는 지뢰가 없습니다.
- 숫자는 주변 8칸에 있는 지뢰의 수를 나타냅니다. 주변에 지뢰가 없는 칸은 이어진 빈 칸을 자동으로 엽니다.
- 지뢰를 밟거나 모든 안전한 칸을 열면 게임이 끝납니다.
- 게임 중 경과 시간과 남은 지뢰 수를 확인할 수 있고, 새 게임 버튼으로 다시 시작할 수 있습니다.

## 어떻게 만들었나요

HTML, CSS, 바닐라 JavaScript로 구현했습니다. 별도 빌드 도구나 패키지 설치 없이 브라우저에서 실행할 수 있습니다.

## freeform 버전과 비교했을 때

이 저장소의 현재 버전은 직접 제시한 기능 요구사항을 바탕으로 구현했습니다. 비교할 freeform 브랜치와 PRD 브랜치가 현재 작업 파일에 포함되어 있지 않아 버전 간 차이는 기록하지 않았습니다.

## 실행 방법

저장소의 `index.html`을 브라우저에서 열면 됩니다.

## 커스터마이징한 부분

반응형 보드와 게임 상태 메시지, 첫 클릭 안전 규칙, 빈 칸 연쇄 열기, 승리·패배 시 입력 종료를 추가했습니다. 보드 크기와 지뢰 수는 [script.js](./script.js) 상단의 `ROWS`, `COLS`, `MINE_TOTAL` 값으로 정합니다.
